# نهر — B2B Employee Enablement Website

Static Arabic RTL landing page for a B2B coaching/training program.

## Includes

- Sand/beige Saudi formal visual identity.
- Lead / needs-assessment form.
- Empty success stories section with placeholders for future photos/logos.
- Technical + financial proposal template in `docs/proposal-template.md`.
- Pricing calculator generated in `files/pricing-calculator.xlsx`.

## Local preview

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.
